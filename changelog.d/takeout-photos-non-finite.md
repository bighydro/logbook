### Fixed
- `google-takeout-photos`, a sidecar number that is `Infinity`, `-Infinity` or `NaN` (Python's json reads and writes them): a coordinate, altitude, view count or timestamp that is not finite is left out of the line as a value the sidecar never had, never written, so the line canonicalises and appends; `geoDataExif` stands in for a `geoData` with an infinite coordinate, the creation time for an infinite taken time. The adapter already did this (`_finite`, `_stamp`, `_int`); it is now pinned by a test. The property test over albums (`test_any_album_yields_only_valid_lines`) wrote its own sidecar with `allow_nan=False` and crashed (`Out of range float values are not JSON compliant: inf`) before the adapter ran whenever Hypothesis drew an infinite timestamp; it writes them as Python spells them now, and draws non-finite coordinates and timestamps on purpose.
