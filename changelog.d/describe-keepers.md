### Added
- `logbook describe keepers [--since DAY] [--limit N] [--photos DIR ...] [--model NAME] [--fetch-model] [--dry-run] [--json]` (`logbook/describe.py`, `docs/describe.md`): a local vision model looks at each keeper's photo (RFC 0024) and writes one factual sentence and a short list of the visible things, as a derived `note/v1` line (RFC 0010) on the photo's day — `source` `description`, tier 2, `raw_id` the photo line's id so a photo is described once however many lanes it is in and however often the command runs, `extra.derived` true, `extra.engine` and `extra.model` naming what wrote it, `extra.photo` the photo as the keeper names it, `extra.keeper`, `extra.things`; the text is the sentence then `Visible: …`, so `search` finds the things. The model sees the pixels and a fixed prompt only — never a name, a date, a location or a face — and is told never to name a person (faces are the library's job, `keepers --people`) and never to guess a place; an answer carrying any word of a face's name the library gave on that photo is refused and counted, never written. The file is found in the record's attachment store (a §1.1 reference under `media`, `attachments`, `file` or `content`) or under `--photos`: an Apple Photos library by the asset UUID under `originals/`, any other folder by file name, case aside, walked once; a keeper whose file is nowhere is a counted skip. The engine is `mlx-vlm` on Apple silicon with `pillow-heif` for HEIC, the new extra `openlogbook[describe]`, default model `mlx-community/Qwen2-VL-2B-Instruct-4bit`, temperature 0, the hub offline while it runs; without the engine or the model the command prints the install and fetch lines and exits 2, and `--fetch-model` is the only network use, as `transcribe` and `promises --judge` have it. `show <day>` prints the description under the first keeper row for its photo, indented to the text column; with no keeper standing it is a row of its own. Synthetic fixtures: the Oslo persona's keepers with a faked engine; a test asserts no socket opens during a run.
