### Changed
- The `encrypted` and `share` extras are one extra, `crypto` (`cryptography` was all either needed): `pip install "openlogbook[crypto]"` reads an encrypted iPhone backup and shares or receives a signed page; `logbook doctor` reports it as `extra:crypto`, and the install line printed when `cryptography` is missing names it. The dev group names the extras it needs (`openlogbook[crypto,ais,mcp]`) instead of repeating their packages.
- The adapter registry is pyproject.toml's `logbook.adapters` entry points alone: every built-in adapter is listed there, in the order `logbook add` tries them on a file, and the package keeps no second list to drift from it; `tests/test_adapter_registry.py` holds the table, the modules under `logbook/adapters/` and the installed metadata to agreement.
- RFC 0025 was two RFCs. The shared page (`docs/rfcs/rfc-0025-shared-page-bundle.md`) keeps the number; the trip bundle is RFC 0030 (`rfcs/0030-trip-bundle-v1.md`). The copies of the RFC index, `location/v1` and `photo/v1` under `docs/rfcs/` are gone and the docs site links to `rfcs/` instead; `activity/v1` and `decision/v1`, never written, left the RFC index; ARCHITECTURE no longer says layer 1 depends on ijson (the Takeout and Dawarich adapters do).
- `tests/test_demo_years.py` (forty synthetic years) is `slow`: it runs on push to main and nightly, not on a pull request. Property tests for the Dawarich adapter, the Takeout `Calendar/` folder, the shared health-export reader and the phone-number normalisation: any input yields only valid lines.
