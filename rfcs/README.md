# RFCs

Payload profiles and spec changes are proposed here as `NNNN-name.md` with a JSON Schema and one synthetic example. Two weeks of comment, then the captain merges or declines with reasons. Seed profiles: [location/v1](0001-location-v1.md), [photo/v1](0002-photo-v1.md), [retraction/v1](0003-retraction-v1.md), [transcript/v1](0004-transcript-v1.md), [resolution/v1](0006-resolution-v1.md), [message/v1](0008-message-v1.md), [event/v1](0009-event-v1.md), [note/v1](0010-note-v1.md), [crossing/v1](0011-crossing-v1.md), [call/v1](0012-call-v1.md), [health-sample/v1](0014-health-sample-v1.md), [flight/v1](0013-flight-v1.md), [mail/v1](0015-mail-v1.md), [task/v1](0016-task-v1.md), [browse/v1](0017-browse-v1.md), [watch/v1](0018-watch-v1.md), [listen/v1](0019-listen-v1.md), [trip/v1, written as journey/v1 since 2026-10-05](0020-trip-v1.md), [transaction/v1](0021-transaction-v1.md), [highlight/v1](0022-highlight-v1.md), [voice-memo/v1](0023-voice-memo-v1.md), [keeper/v1](0024-keeper-v1.md), [weather/v1](0026-weather-v1.md) (drafts); [story/v1](0028-story-v1.md) (draft, unfinished: a told story, as distinct from an observed event; open questions for its non-technical co-author at the end); bundle formats: [crossing-package/v1](0005-crossing-package-v1.md), [shared-page/v1](../docs/rfcs/rfc-0025-shared-page-bundle.md), [trip-bundle/v1](0030-trip-bundle-v1.md) (the shared trip, with `trip-share/v1` and `received/v1`); the envelope: [encryption at rest for tiers 2–3](0029-encryption-at-rest.md) (RFC 0029, adopted; it defines `sealed/v1`, the reference a sealed line's payload holds, and `rekey/v1`, the line a reseal appends). Mechanism RFCs, which change a reader and no line, live beside the docs: [0027 Reflection](../docs/rfcs/0027-reflection.md), the digest's closing question from the record's own bank; [0031 Profile freeze for v1.0](../docs/rfcs/0031-profile-freeze.md) (draft), which sorts every profile into frozen, parked or deleted for v1.0, with the letter to builders in [docs/letters/](../docs/letters/2026-10-04-the-freeze.md).
